# Product Card UI Component

this is a responsive, styled product card web page.that has a product discount badge,image animation,and action buttons.

## Features

* **Sticky Navigation Bar**: Remains fixed at the top of the page.
* **Product Card Layout**: display product tags, product image, pricing.
* **Hover Effects**:
  * image scaling on hover over the image.

## how to access

1. **Clone or download** this repository.
2. **Ensure your product image file** is located in the root directory named `image.png`, or you can change the path of it in the html file.
3. **Open `index.html`** in your web browser.
